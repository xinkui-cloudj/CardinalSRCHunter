# CardinalSRCHunter
This program is an AI-assisted domain information analysis learning tool, intended solely for cybersecurity technical research and testing within authorized environments.

Users must ensure they have obtained valid administrative authorization for all target domains under test. Unauthorized site information collection, site inspection, access to site resources, or any operation violating laws and regulations is strictly prohibited.

AI-generated outputs are for reference only. Results may contain false positives, omissions or inaccuracies and shall not constitute security guarantees or legal advice.

All risks and liabilities arising from the use, misuse, distribution, modification or redistribution of this program shall be borne solely by the end user. The developer assumes no joint liability. By downloading or using this program, you agree to this disclaimer.

This is a lightweight, portable tool designed for quick setup and technical research. Due to its simplified design, its capabilities are limited. It is not as powerful as full-featured AI scanning solutions with multiple integrated tools, and is not intended for professional production use.

On first installation, launch the program and click the "One-Click Install" button to set up the prerequisite environment. Then click the "Web Console" button to open the console. Go to the "Endpoints & API" page, complete the configuration and click Save. After installing the skill tools and MCP plugins, you can start using the program.
